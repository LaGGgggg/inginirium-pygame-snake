### Змейка

Классическая игра «Змейка» на Python и pygame с таблицей рекордов в SQLite

#### Установка и запуск

1. Клонируйте репозиторий и перейдите в него:
    `git clone https://github.com/LaGGgggg/inginirium-pygame-snake && cd inginirium-pygame-snake`
2. Установите [Python](https://www.python.org/downloads/) версии 3.11–3.13
3. Установите [uv](https://docs.astral.sh/uv/getting-started/installation/)
4. Запустите: `uv run main.py`

#### Управление

- Стрелки или WASD - движение змейки.
- Меню: ввод никнейма, Enter - начать игру.
- Конец игры: Enter - в меню, S - таблица рекордов, Q - выход.
- Таблица рекордов: Escape - в меню.

#### Победа

В игре предусмотрено условие победы: нужно набрать больше 200 очков (съесть больше 20 яблок)

#### Логирование

Все действия с базой данных логируются в консоль с уровнем `DEBUG`. Для отключения логирования
необходимо в файле `config.py` изменить значение переменной `LOGGING_LEVEL`.
