### Змейка

Классическая игра «Змейка» на Python и pygame с таблицей рекордов в SQLite

#### Установка и запуск

1. Установите [Python](https://www.python.org/downloads/) версии 3.11–3.13
2. Установите [uv](https://docs.astral.sh/uv/getting-started/installation/)
3. Запустите: `uv run main.py`

#### Управление

- Стрелки или WASD - движение змейки.
- Меню: ввод никнейма, Enter - начать игру.
- Конец игры: Enter - в меню, S - таблица рекордов, Q - выход.
- Таблица рекордов: Escape - в меню.

#### Победа

В игре предусмотрено условие победы: нужно набрать больше 200 очков (съесть больше 20 яблок)
